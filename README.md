# 📊 HR & Employee Analytics (SQL Project)

## 📌 Project Overview
This project demonstrates my SQL skills by analyzing a simulated HR database. It includes two related tables (`employees` and `departments`) and answers real-world business questions using advanced SQL techniques.

## 🛠️ Skills Demonstrated
- **DDL (Data Definition Language):** Creating tables with Primary and Foreign Keys.
- **DML (Data Manipulation Language):** Inserting relational data.
- **JOINs:** Combining data from multiple tables (`INNER JOIN`).
- **Aggregations:** Using `COUNT`, `SUM`, `AVG`, and `GROUP BY`.
- **Subqueries:** Filtering data based on aggregated results.
- **Functions:** Date (`YEAR`), String (`CONCAT`, `SUBSTRING`), and Handling NULLs (`IFNULL`).

## 📂 Files in this Repository
- `01_schema_and_data.sql`: The script to create the database, tables, and insert sample data.
- `02_analysis_queries.sql`: The file containing the 6 business analysis queries.

## 💡 Key Business Questions Answered
1. Who are the top 3 highest-paid employees?
2. What is the average salary and total payroll for each department?
3. Which employees were born after 1995 in the Engineering department?
4. How do department managers and budgets relate to employees?
5. Who earns more than the company average?
6. How can we clean up and format employee contact info?
